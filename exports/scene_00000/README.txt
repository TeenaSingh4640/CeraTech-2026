Structured3D Scene - 3D Model Export
==================================================

Scene: dummy_dataset/scene_00000

Exported Formats:
- scene.obj  - Universal 3D format (use in Blender, Maya, 3ds Max)
- scene.stl  - 3D printing format (use in slicing software)
- scene.gltf - Web/game format (use in Unity, Unreal, Three.js)

Import Instructions:
- Blender: File > Import > Wavefront (.obj)
- Unity: Drag .gltf into Assets folder
- 3D Printer: Load .stl in your slicer software
