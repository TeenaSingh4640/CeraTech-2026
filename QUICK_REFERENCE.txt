🚀 INTERACTIVE 3D VIEWER
  python visualize_3d.py --path dummy_dataset --scene 0 --type wireframe
  python visualize_3d.py --path dummy_dataset --scene 1 --type wireframe
  
  Controls:
    • Left-click + drag = Rotate
    • Scroll wheel = Zoom
    • Right-click + drag = Pan
    • Q = Close

🔧 TROUBLESHOOTING
  If images don't load:
    1. Refresh browser (F5 or Ctrl+R)
    2. Check file paths are correct
    3. Ensure you're in Structured3D/ directory
  
  If 3D viewer doesn't work:
    1. Check open3d installed: pip list | findstr open3d
    2. Run from correct directory
    3. Verify scene folder exists
