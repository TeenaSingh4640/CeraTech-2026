## 📐 Technical Parameters for All Renderings

### Structural Grid Parameters
```
Bay Spacing: 7.14m × 7.50m
Grid Pattern: 7 bays (50m) × 4 bays (30m)
Total Columns per Floor: 40 (8 × 5 grid)
Column Spacing (visual rhythm): ~7m
```

### Column Sizes (Visual Expression)
```
Ground Floor:  700mm × 700mm (prominent)
Floor 5:       550mm × 550mm (mid-height)
Floor 10:      300mm × 300mm (slender top)
```

### Beam Dimensions (Horizontal Expression)
```
Primary Beams: 250mm wide × 300mm deep
Visible depth at façade: 300mm
Creates horizontal banding at each floor
```

### Façade Module
```
Typical Window Width: ~7.14m (aligned with bays)
Spandrel Height: ~1.0m (typical)
Vision Glass Height: ~2.4m (typical)
Floor-to-Floor: 3.5m
```

### Material Palette
```
Primary Structure: Fair-faced concrete (light grey)
Columns: Exposed concrete or clad
Glazing: High-performance low-E glass
Shading: Aluminum or concrete brise-soleil
Accent: Natural stone or wood at entry
```

### Climate-Responsive Features (Mumbai)
```
- Deep overhangs (1.5-2.0m) on south/west
- Vertical fins on west façade
- Operable windows for natural ventilation
- High-performance glazing (SHGC < 0.25)
- Green terrace to reduce heat island
- Rainwater harvesting visible features
```

## 💡 Pro Tips for AI Image Generation

If using AI tools (Midjourney, DALL-E, Stable Diffusion):

1. **Start Simple:** Use Prompt 1 first, then add details
2. **Iterate:** Generate multiple versions, refine
3. **Consistent Style:** Use same style keywords across views
4. **Technical Accuracy:** Include actual measurements for AI to understand scale
5. **Reference Images:** Provide similar building references if possible
6. **Negative Prompts:** Exclude unwanted elements (cartoon, unrealistic, distorted)
7. **Upscale:** Always upscale final selections to 4K

### Negative Prompt Template:
```
cartoon, anime, sketch, drawing, unrealistic proportions, distorted perspective, 
oversaturated colors, fantasy architecture, impossible structures, poor quality, 
blurry, low resolution
```
